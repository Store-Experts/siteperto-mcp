# Segurança

Não publique credenciais, arquivos privados de clientes ou dados pessoais em issues, exemplos ou relatórios públicos. Para comunicar uma possível falha, use o suporte autenticado no painel SitePerto; informe o produto, a versão e uma reprodução sintética sem segredos.

Os arquivos deste repositório são somente a integração pública. O serviço de autorização e o editor pertencem à plataforma; não incluímos credenciais, bases de dados ou código privado do serviço.

As permissões são somente `site.read` e `site.update`, específicas do site escolhido. Nenhuma ferramenta publica, altera domínio ou acessa contatos e cobrança. Uma saída HTML é conteúdo público: revise-a antes de enviar.
